# Influencer-Outreach-Message-Generator
The Influencer Outreach Message Generator is an AI-powered influencer marketing CRM platform developed using Python, Streamlit, Groq LLM, SQLite, Pandas, and Plotly. The system automates personalized influencer communication by generating AI-powered outreach messages, follow-up emails, and collaboration proposals based on influencer profiles, campaign goals, and communication tone. The platform also includes campaign management, sentiment analysis, collaboration tracking, analytics visualization, AI prompt logging, and SQL-based data management within an interactive Streamlit dashboard. This project demonstrates the practical implementation of Generative AI in influencer marketing automation, campaign analytics, and intelligent communication workflow management.
